# Bankist - Modern Banking Simplified

Bankist is a modern banking website prototype featuring a clean, minimalist design with advanced UI interactions like smooth scrolling, tabbed components, lazy loading, and a dynamic testimonial slider.

## Features

- **Responsive Design:** Fully functional across mobile, tablet, and desktop devices.
- **Dark Mode:** User-preferred appearance settings saved via local storage.
- **Dynamic Interactions:** Includes smooth scrolling, sticky navigation, and reveal-on-scroll animations.
- **Banking Operations:** Simulated instant transfers, loan requests, and account management.
- **Persistence:** Uses `localStorage` to persist account data across sessions.

## Deployment

This is a static website and can be deployed easily on several platforms:

### 1. Vercel / Netlify
- Drag and drop the project folder onto the dashboard.
- Or connect your GitHub repository for automatic deployments.

### 2. GitHub Pages
1. Initialize a git repository: `git init`
2. Add all files: `git add .`
3. Commit: `git commit -m "Initial commit"`
4. Push to a GitHub repository.
5. Go to Settings > Pages and select the `main` branch.

### 3. Local Development
Simply open `index.html` in your browser, or use a local server like "Live Server" in VS Code for the best experience.
